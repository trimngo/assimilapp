Drive download test

This separate page checks whether your browser can download and save public Google Drive files. It leaves your study progress, timings and imported files alone.

  1. Make the PDF and one MP3 accessible to Anyone with the link, then paste each individual file link below.
  2. Download each file. This must succeed here; opening its Drive preview is a different test.
  3. Wait for Test page available offline, turn on Airplane Mode, reload this page, and open the saved PDF and play the MP3.

No Google login or API key is used. The app downloads the original files, with no conversion. Test downloads use extra space on this device.
